# Темы и иконки — отдельный аддон PALACE

Готовый файл: [`../appearance.palace-addon`](../appearance.palace-addon).

1. В приложении откройте **Аддоны**, загрузите `.palace-addon` и нажмите **Установить**.
2. Нажмите новый значок палитры слева либо команду **Темы и иконки: открыть каталог** в менеджере аддонов.
3. Выберите цветовую тему и набор иконок. Выбор применяется сразу и хранится в этом браузере.

В комплекте темы **Океан**, **Фиолетовый**, **Светлая бумага** и два набора иконок — угловой и округлый. Можно выбирать и все встроенные темы PALACE. Наборы заменяют указанные SVG-иконки интерфейса; остальные иконки остаются системными.

## Свои наборы

В панели выберите JSON-файл в поле **Установить свой набор**. Наборы добавляются к каталогу; повторный импорт того же ID обновляет пользовательский набор. **Показать пример JSON** выводит текст, который можно скопировать в свой файл. Полный пример: [catalog.json](catalog.json).

```json
{
  "themes": [{
    "id": "palace.appearance.my-theme",
    "title": "Моя тема",
    "base": "darcula",
    "mode": "dark",
    "colors": {"editor": "#15252d", "widget": "#21343d", "focus": "#419cc2"},
    "canvas": {"bg": "#15252d", "walls": "#419cc2"}
  }],
  "iconThemes": [{
    "id": "palace.appearance.my-icons",
    "title": "Мои иконки",
    "icons": {"i-camera": [{"d": "M2 2H14V14H2Z", "filled": false}]}
  }]
}
```

ID импортируемых наборов начинается с `palace.appearance.`; цвета — `#RRGGBB`. `base` — ID встроенной темы, `mode` — `dark` или `light`. Для иконок указываются ID существующих SVG-символов PALACE (`i-camera`, `i-folder`, `i-plan`, `i-save` и т. п.). Пути используют исходную систему координат символа, обычно 16×16. Полный SVG, внешние ссылки и произвольный CSS не принимаются. Это формат PALACE; пакеты тем VSCode и `.vsix` не поддерживаются.

JSON ограничен 80 КБ; общее число тем и наборов — 30. Импортированные наборы хранятся вместе с настройками аддона в IndexedDB. Их можно удалить отдельной кнопкой. **Системное оформление** переключает на Darcula и исходные иконки. При отключении/удалении аддона его темы и наборы снимаются; изображения планов и данные дворца не меняются.

Сборка:

```sh
node scripts/package-addon.cjs addons/appearance addons/appearance.palace-addon
```
