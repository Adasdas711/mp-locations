# Проверка приложения — 12 октября 2026

Проверены существующая регрессия и дополнительные сценарии ошибок, параллельных операций и смены проекта. Исходные 190 тестов прошли, но дополнительные проверки воспроизвели восемь багов.

После исправлений полный `npm test`: **211 тестов прошли, 0 ошибок, 0 пропусков**, продолжительность 293,4 секунды. `npm run build`, проверка синтаксиса изменённых JavaScript-файлов и `git diff --check` прошли. Минифицированный `index.html` собран, версия офлайн-кэша обновлена.

## Найдено и исправлено

| Баг | Изменение |
| --- | --- |
| После назначения обычной буквы палитре команд она перехватывала ввод в текстовых полях. | Ввод без Ctrl/⌘/Alt остаётся в поле; повторное удержание клавиши не сбрасывает палитру. |
| Ctrl/⌘+P открывал палитру поверх редактора `meta.json` и других диалогов. | Активные диалоги сохраняют ввод и фокус; из настроек палитра по-прежнему открывается. |
| Повторное включение палитры забирало сохранённую клавишу, уже назначенную другой команде. | Конфликтующая привязка палитры снимается с объяснением в её настройках. |
| При ошибке записи аддон видел новое значение `storage`, которое фактически не сохранилось. | Значения в памяти меняются только после успешного завершения записи в IndexedDB. |
| Одновременные запросы к настройкам аддона теряли часть изменений. | Записи одного аддона выполняются последовательно, с учётом последних сохранённых полей. Включение, удаление и обновление используют ту же очередь. |
| После неудачной загрузки Three.js повторное открытие 3D снова завершалось ошибкой без нового запроса. | Неудачная загрузка освобождает кэш обещания и удаляет неработающий script; повторная попытка загружает движок заново. |
| Загрузка плана через API могла закончиться уже после открытия другого дворца и добавить старый план в новый проект. | Перед добавлением проверяется, что проект остался прежним. |
| Незавершённое объединение старых планов могло удалить этаж нового дворца. | После загрузки изображений и сборки плана проверяется проект; отменённая операция не откатывает новый дворец. |

Для этих сценариев добавлен [audit-regression.cjs](audit-regression.cjs): 21 тест, включая desktop, Android, iPhone и iPad. Параллельные запросы проверяются через API настоящего изолированного iframe аддона, затем проверяется сохранность данных после перезагрузки. Смена проекта проверяется открытием другого архива во время задержанной операции.

## Объём проверки

- Загрузка изображений, PDF и архивов `.mplace` / `.mpalace` / `.3dview`, вложенные и повреждённые архивы; экспорт и повторное открытие.
- Этажи, объединение и разделение планов, локусы, заметки, стены, порядок маршрута, Undo/Redo.
- Камеры, панорамы, переходы, начальная камера, пунктирные связи, управление на значках, 2D/3D и миникарта.
- Пять режимов повторения и выход из них; режим просмотра, настройки, темы, значки, масштаб интерфейса и горячие клавиши.
- Аддоны, разрешения API, изоляция, установка/обновление/удаление, история изменений и пресеты рабочего пространства.
- Автосохранения с метаданными и бинарными ресурсами, офлайн-кэш, обновление service worker и проверяемые браузерные сценарии PWA.
- Мобильные касания, перетаскивание, масштабирование и смена ориентации; нагрузочная проверка зума с 200 камерами.

Дополнительная проверка геометрии окон настроек охватила 720 сочетаний: 15 разделов, темы Darcula/Paper/Borealis, три размера интерфейса и четыре профиля экрана; отдельно горизонтальный экран 844×390 с крупным интерфейсом. Переполнения по горизонтали и выхода окон за экран не найдено. Это проверка геометрии, а не сравнение каждого пикселя со скриншотом.

## Границы проверки

Мобильные профили запускались в Chromium с эмуляцией размера экрана и касаний. Физические устройства и Safari не проверялись. Установить WebKit для локального прогона не удалось: официальные серверы загрузки вернули `403 Domain forbidden`. Репозиторий содержит отдельный CI-прогон WebKit; его результат в этот отчёт не включён.

Отказы внешних сервисов туров и диалог установки PWA проверяются управляемыми браузерными сценариями. Доступность всех внешних провайдеров и установка на физический телефон не проверялись.
