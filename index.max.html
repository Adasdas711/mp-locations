3D-тур

Вставьте ссылку на тур в поле сверху и нажмите «Открыть». Ниже — как найти эту ссылку на почти любом сайте.

  1. Откройте страницу объявления с 3D-туром (Redfin, сайт агентства).
  2. Посмотрите, чей это тур. Логотип обычно виден в углу самого тура: Matterport, iGUIDE, Kuula, CloudPano.
  3. Откройте инструменты разработчика — F12 или Ctrl+Shift+I (на Mac ⌥+⌘+I), вкладка Elements.
  4. Найдите тур в разметке: Ctrl+F внутри панели и поиск по слову iframe, либо по названию сервиса — matterport, youriguide, kuula.
  5. Скопируйте адрес из атрибута src найденного <iframe> и вставьте сюда.

Быстрые способы без консоли: правый клик по туру → «Открыть фрейм в новой вкладке»; либо кнопка «Поделиться» у самого тура — там часто есть готовый код вставки.

Как выглядят ссылки щёлкните по образцу — скопируется
Matterport my.matterport.com/show/?m=ID встраивается
iGUIDE youriguide.com/адрес встраивается
Kuula kuula.co/share/ID встраивается
CloudPano app.cloudpano.com/tours/ID встраивается
Asteroom my.asteroom.com/player/?id=ID встраивается
EyeSpy360 eyespy360.com/…/tour/ID встраивается

Zillow 3D Home: сайт блокирует показ тура во фрейме, вставка ссылки сюда не поможет. Вместо этого — офлайн-выгрузка без единого клика: python3 zillow_tour_grabber.py → вставьте ссылку на тур в открывшееся окошко → получится файл data.3dview с панорамами, планом и точной привязкой комнат. Откройте его кнопкой «Открыть» в этом редакторе (или перетащите на окно) — появятся этаж, локусы и свой 3D-просмотр панорам, без всякого iframe.
